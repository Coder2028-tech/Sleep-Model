The Guide to My Sleep Model

Why did I choose to create this project?

Lack of sleep is very common among high school and college students, who often prioritize homework and activities over rest. I wanted to create an AI-based tool to determine how much sleep someone needs based on key factors like age, energy, anxiety, daily activity, and brain performance.

How does this project work?

I created two models: a manually-coded model and a machine learning model. The manual model used conditional statements, while the ML model was trained on sample data using a Random Forest Regressor to predict sleep hours.

The ML model proved more accurate because it identified patterns in the data rather than relying on arbitrary human rules.
